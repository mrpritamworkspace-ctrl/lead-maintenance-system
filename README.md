# Lead Maintenance System

A simple JavaScript-based Lead Management Dashboard for collecting,
storing, and managing business leads.

## Features

- Add new leads
- Store leads using localStorage
- Display all leads
- Separate New Leads
- Separate Contacted Leads
- Lead status management
- Form validation
- Responsive dashboard UI

## Lead Information

Each lead contains:

- Name
- Phone
- Course / Service
- Preferred Time
- Lead Status

## Project Flow

User fills the form
→ Lead object is created
→ Lead is stored in localStorage
→ Dashboard displays the lead
→ Lead is categorized by status
